# 渲染诊断、预算与合入门槛

## 诊断面板信息架构

面板分为五组：

1. **适配器与能力**：发行形态、客户端/适配器构建、R0-R3、每个 capability 的 status/evidence/失效时间、最近权限拒绝和降级原因。
2. **对象与预算**：按模组统计模型、粒子、UI、音效、观察订阅、活动句柄；创建/更新/销毁计数；预算、拒绝和软降级次数。
3. **资源**：资源指纹、待加载/已加载/失败、估算内存、重复资源、引用计数、release-pending；不输出完整对象树或用户文件。
4. **性能**：跨语言调用、慢调用、UI 重建/提交、每帧脏提交、帧时间 P50/P95/P99、与丢帧同刻相关性；日志采样而非每帧全量。
5. **效果仲裁**：效果层 priority/exclusiveGroup、当前胜者、被拒绝者和 fallback；可导出脱敏问题报告。

问题报告默认排除聊天、账号、IP、跨平台 ID、无关文件和完整坐标轨迹，只包含版本、能力报告、资源哈希、预算摘要、错误码、时间窗和用户主动选择的失败截图。

## 建议预算（必须用真实设备校准）

| 档位 | 单模组活动对象 | 全局表现对象 | 每帧更新 | UI 提交/重建 | 资源内存 | 粒子/轨迹 |
|---|---:|---:|---:|---:|---:|---:|
| mobile-low | 64 | 256 | 0.5 ms | 2/1 次 | 16 MiB | 128/秒 |
| mobile/console | 128 | 512 | 1.0 ms | 4/2 次 | 32 MiB | 256/秒 |
| desktop | 256 | 1024 | 2.0 ms | 8/4 次 | 128 MiB | 1024/秒 |

资源加载并发建议 2（低档）/4（普通），单资源超时 5 秒，跨语言调用建议单模组 60 次/秒、全局 300 次/秒。超过硬上限拒绝；接近上限先减少远距、低优先级、透明和更新频率；向模组发出结构化预算事件。不能让一个模组拖垮客户端。

低帧率连续 10 秒降一级；低内存先拒绝新资源，再卸载可重建的实验对象；集显/移动设备禁用高频轨迹和实验屏幕效果；用户可在诊断面板看到原因和恢复条件。

## 稳定性 API 冻结清单

**v1 稳定：**资源注册索引、白名单粒子提交、白名单空间音效、action bar、物品使用事件、只读实体观察（状态严格区分）、权限/预算/诊断、BLSP/1 安全校验、统一 dispose。

**v1 experimental：**动态动画播放描述、资源变体、世界 UI 请求、运行时挂点、相机事件、资源热重载、客户端实体组合、模拟世界测试 API。

**custom-client-only：**Shader、帧缓冲、命令列表、任意几何/材质上传、渲染层、深度/透明排序、原生相机回调、程序化骨骼矩阵。

**移除：**任何绕过签名、注入、Hook、私有符号、二进制补丁和“成功即必然可见”的接口语义。

## 贡献者渲染功能合入检查表

- [ ] 写明 R0/R1/R2/R3 目标等级和国际版实际等级。
- [ ] 引用公开接口、版本、权限和资源格式；禁止私有符号和猜版本。
- [ ] 给出最小实验、自动断言、失败截图/人工限制和有效期。
- [ ] 明确 `created/submitted/first_visible/stable_visible/degraded` 语义。
- [ ] 有预算归属、超限拒绝、软降级、fallback 和多模组仲裁。
- [ ] 覆盖世界切换、维度、死亡、传送、断线、热禁用和重复销毁。
- [ ] 位置/时间标注 authoritative、sampled 或 predicted；不把预测当权威。
- [ ] 资源引用、缓存失效、release-pending 和泄漏测试齐全。
- [ ] 文档、能力矩阵、路径台账、用户报告示例同步更新。
- [ ] 构建通过；不得使用“已接入渲染管线”“跨平台一致”等绝对表述。
