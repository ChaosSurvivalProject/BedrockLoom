# 03 · 底包结构「假设」（**非实测**）

> ⚠️ 本文件全部内容都是**为了组织解析器而设的分类假设**，不是 1.21.130 的实际目录结构。
> 按 [01 门禁](01-local-path-gate.md)，本机无包，静态解析未执行。
> 任何在此出现的路径名都只作为「假设类别」，不得当作事实、不得写进代码常量、不得据此推断偏移。

## 1. 为什么还要写一份假设

解析器需要先约定**它要接受什么样的输入**，才能做到「路径由环境变量传入、未知格式一律 `unsupported`」。这份假设只用于定义解析器的输入契约与拒绝行为，不用于描述游戏。

它与实测的区别：

| 维度 | 实测（未执行） | 本文件 |
| --- | --- | --- |
| 目录名 | 来自真实解包 | 抽象占位 `<target>` |
| 文件布局 | 逐项列举 | 只列「类别」 |
| 头部/块结构 | 真实字节 | 只定义通用魔数/块表读取接口 |
| 结论 | 可引用 | **不可引用**，无证据级别 |

## 2. 假设的输入契约

解析器 `parser/layout.mjs` 只接受一个由环境变量给出的根目录：

```
BLR_TARGET_DIR=<绝对路径>          # 必需；缺失即拒绝
BLR_MAX_FILES=<整数>               # 可选，默认 2000；超出返回 resource-exhausted
BLR_MAX_BYTES=<整数>               # 可选，默认 64 MiB；超出返回 resource-exhausted
```

不扫描全盘、不猜默认路径、不联网、不写回源目录。

## 3. 假想的类别划分（抽象，非真实路径）

```
<target>/                          # 作者本机解包根目录（假设）
├── <metadata>                     # 类别 M：清单 / 版本 / 签名描述文件
├── <resources>                    # 类别 R：静态资源（纹理、模型、动画、UI、音效定义）
├── <scripts>                      # 类别 S：脚本上下文与公开 Script API 模块声明
├── <renderer-desc>                # 类别 D：渲染相关描述/配置（**不是**渲染代码）
└── <binary>                       # 类别 B：可执行/着色/材质二进制（**只读元数据，不解析内容**）
```

每条说明：

| 类别 | 解析器允许做什么 | 解析器禁止做什么 |
| --- | --- | --- |
| M 元数据 | 文件名、大小、SHA-256、JSON 是否为合法 JSON（布尔） | 输出内容、推断字段含义 |
| R 静态资源 | 文件名、大小、SHA-256、扩展名分布 | 输出纹理/模型内容、解码图片 |
| S 脚本上下文 | 文件名、大小、行数统计 | 输出源码、推断私有模块名 |
| D 渲染描述 | 文件名、大小、通用头魔数 | 解析材质结构、推断 shader 变体、写偏移 |
| B 二进制 | **仅**文件头前 32 字节的通用魔数分类 + 大小 + SHA-256 | 解析块表内容为语义、反汇编、输出样本 |

**关键**：类别 B 的「块表」只允许读**通用容器头**（长度/计数/版本这类无语义字段），且结果以 `unsupported` 返回时不得伪造字段含义。任何「这个块是 PBR 材质 / 这个是渲染通道」的判断都不在本仓库范围内。

## 4. `material.bin` 的处理

用户目标里点名 `material.bin`。本仓库的立场：

- ✅ 可以**记录**「存在一类渲染材质描述文件」这个类别；
- ✅ 解析器可以给出它的大小、SHA-256、通用头魔数（不含样本字节输出）；
- ❌ **不提供** `material.bin` 的结构定义、字段偏移、版本表、样本；
- ❌ **不修改**、不生成、不回写任何材质文件；
- ❌ 不把 Java 侧材质/模型结构套过来。

理由：这属于「游戏提取资源」与「私有符号表」，是硬边界第 2、8、9 条明令排除的内容。

## 5. 假设与证据的隔离写法

文档中凡提及具体结构，必须带以下前缀之一：

- `【实测】` —— 本文件**当前没有任何实测条目**；
- `【用户目标】` —— 来自需求描述，未经核实；
- `【假设】` —— 为本仓库解析器设计而设，不代表实际布局；
- `【未验证】` —— 结论待作者本机合法条件确认。

代码里**不允许**出现任何 `【假设】` 类别对应的硬编码真实路径或符号。
