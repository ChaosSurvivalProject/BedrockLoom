# 能力降级矩阵

> 本表是能力声明，不是渲染管线承诺。`待验证` 必须经过 [八个标准探针场景](PROBE_SCENARIOS.md)；`R0` 表示资源表达，`R1` 表示有限运行时驱动，R2/R3 需要正式公开扩展或授权。

| 能力 | 国际版 1.21 普通客户端 | 服务端兼容 | 网易预留 | 定制客户端目标 | 降级 |
|---|---|---|---|---|
| 模型/材质（R0） | 资源包 attachable + geometry；注册不创建运行时实例（待验证） | 不需要 | 空实现 | 可由授权 SPI 提供 | 使用原版占位图标 |
| 待机/攻击动画（R0/R1候选） | animation + controller + 本地状态（待验证） | 可请求已白名单 clip | 空实现 | 可提供受控运行时混合 | 静态模型 |
| 粒子（R1候选） | particle 定义与本地脚本（待验证） | 可请求白名单 effect | 空实现 | 可提供参数化实例 | 无粒子 |
| 音效（R1候选） | sound_definitions + 本地脚本（待验证） | 可请求白名单 sound | 空实现 | 可扩展音频层 | 无音效 |
| 世界空间 UI（R1） | 当前无通用公开提交，`unsupported` | 仅请求模板和 TTL | 空实现 | 授权 UI 扩展 | action bar/toast |
| 屏幕 UI（R1受限） | 当前稳定承诺仅 action bar/toast | 仅请求已声明 toast | 空实现 | 可提供声明式 UI | 无 UI |
| 输入（R1事件） | Script API 本地事件 | 不开放服务端注入 | 空实现 | 可提供受控输入层 | 默认按键/物品事件 |
| 相机效果（R2候选） | 仅本地事件，当前无画面承诺 | 受幅度和时长上限 | 空实现 | 需授权相机扩展 | no-op |
| 实体挂点与观察 | 观察依赖 `getEntities`；运行时挂点仅 experimental | 仅引用本地实体，不改变权威状态 | 空实现 | 可提供版本化挂点 | 玩家中心；观察返回 unavailable |
| 本地存档 | 当前 `StorageApi` 为内存兼容层 | 服务端不可写 | 空实现 | 可接持久化 SPI | 重进丢失 |
| 输入绑定 | `InputApi` + 本地事件 | 不开放服务端注入 | 空实现 | 可提供硬件抽象 | 物品事件 |
| 事件总线 | `ClientEventBus` 模组内分发 | 不跨越权限边界 | 空实现 | 可跨适配器 | 直接回调 |
| 权限门 | `PermissionGate` manifest 权限 | 服务端不能授予 | 空实现 | 可接许可系统 | 拒绝调用 |
| 原生渲染 Hook（R3） | `unsupported`；不注入、不扫描私有符号 | 不授予 | 不实现 | 仅签名 Render Extension SPI | 官方资源管线 |

无论何种降级，都不能把本地视觉请求提升为多人权威玩法。
