# 八个标准渲染探针场景

所有场景固定种子、时间、天气、分辨率、画质、相机和玩家姿态；记录能力报告、资源指纹、对象计数、帧时间和清理结果。截图接口若非官方测试能力，只能人工验收并标记 `manual-visual`。

| 编号/场景 | 输入 | 预期与允许误差 | 失败判定 | 性能与清理 |
|---|---|---|---|---|
| S1 三距离模型 | 原点前 2/16/48 格放同一标准模型 | 近中可见、远距按能力剔除；位置误差 <= 1 格，尺度误差 <= 5% | 资源错位、近处不可见或未按能力报告剔除 | 记录 3 对象/帧时间；退出后对象=0 |
| S2 右手挂点 | 玩家走动、转身、播放预设动画 | 模型随玩家移动/转身；只验资源挂点，不宣称骨骼 Hook | 未绑定、漂移 > 0.25 格、跨会话残留 | 60 tick 更新；重进世界无旧句柄 |
| S3 三层透明面 | 红/绿/蓝三块预声明透明面前后交叠 | 记录游戏实际排序；不得预期可控排序 | 与基线差异超容差，或错误宣称排序可控 | 透明对象预算；禁用模组后无资源新增 |
| S4 实体轨迹 | 实体沿固定路径移动 120 tick | 粒子点跟随采样位置，允许 1 tick 延迟；没有稳定 Trail 时标 degraded | 点不更新、超预算、生命周期不收敛 | 记录每 tick 调用；停止后 2 秒内句柄=0 |
| S5 遮挡高亮 | 墙前后同类标记 | 只报告可见/不可见和游戏默认深度；不承诺穿墙描边 | API 声称可控但画面不符 | 近远各 30 秒；销毁全部标记 |
| S6 范围预警面 | 固定圆/方范围，100 个采样点 | 地面贴合误差 <= 0.5 格；超出能力转粒子/关闭 | 大量掉帧、点穿地或清理失败 | 记录对象、帧时间；禁用后无粒子与订阅 |
| S7 屏幕+世界 UI | action bar 与资源层标记同时存在，桌面/移动 DPI | action bar 可读；世界 UI 若 unsupported 必须显示降级说明；焦点不抢聊天 | 文字裁切、输入被吞、状态误报 | UI 重建/提交计数；退出世界清空 active |
| S8 相机与色彩 | 请求 pulse/FOV/闪白/色差，叠加和超时 | 普通国际版无 Hook 时报告 no-op/degraded；授权适配器才验画面 | 调用 true 却无状态说明；效果不自动关闭 | 记录优先级、超时、丢帧；40 tick 后效果层=0 |

## 验收分层

- A：对每个场景验证输入校验、固定时间步、预算、重复创建/销毁和异常隔离。
- B：真实客户端/官方支持测试环境验证视野内、遮挡、距离、画质、退出重进、断线重连和热禁用清理。
- C：黄金图比较中心/边缘、近/远、昼夜、透明/遮挡、移动/静止；使用结构化区域容差，不用“看起来像”。
